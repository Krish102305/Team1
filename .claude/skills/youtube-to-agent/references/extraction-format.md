# Extraction format

Both viewers (Claude and Gemini) must produce exactly these sections, in
Markdown, so the outputs can be compared item by item. Attach a `[mm:ss]`
timestamp to every item. Report only what the video shows or says — no
inferred steps, no outside knowledge; write "not shown" when something is
missing.

## Goal
One or two sentences: what the finished thing does.

## Prerequisites
Accounts, API keys, software, versions, hardware.

## Steps
Numbered, in the order performed. For each: the action, and the exact
command / code / UI path / setting value shown on screen.

## Code and config
Every code block, prompt, or config file visible on screen, verbatim, with
the file name if shown.

## Inputs and outputs
What the finished workflow takes in and what it produces.

## Gotchas
Errors, warnings, caveats, or workarounds the presenter mentions.

## Unclear
Anything you could not read or hear reliably.
